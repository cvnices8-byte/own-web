# 邵锦波 · 个人简介网站 (Personal Portfolio)

Personal portfolio site for **Shao Jinbo** (邵锦波) — Audit × Data Science hybrid profile.

🌐 **Live**: https://cvnices8-byte.github.io/own-web/

## 技术栈 / Stack
- 纯静态站 / Pure static: HTML + CSS + JS
- 图表 / Charts: [ECharts](https://echarts.apache.org/) (CDN)
- 部署 / Deploy: GitHub Pages

## 双主题 / Dual Themes
- **暗色 / Dark** — ASCII terminal style (参考 ascii-magic.com)
- **亮色 / Light** — Clean modern MiMo style (参考 mimo.mi.com)

## 本地预览 / Local Preview

cd site
